# Trekkelon – Pack Smart. Travel Confident.

**Live Demo:** [Try Trekkelon](https://trekkelon-pack-smart-travel-confide.vercel.app)

Trekkelon is an AI-powered travel packing assistant designed to make packing smarter, simpler, and more organised. It helps travellers prepare for their journeys by organising luggage, checking baggage restrictions, and identifying potentially restricted items.

## Features

### 1. Personalised Traveller Profiles
Choose from different traveller profiles:
- Solo Traveller
- Female Solo Traveller
- Family Traveller
- Business Traveller
- Last-Minute Traveller

Packing suggestions and essentials are tailored to the selected profile.

### 2. Multiple Travel Modes
Supports different modes of transportation:
- Flight
- Train
- Bus
- Bike

Each mode comes with relevant baggage categories and weight limits.

### 3. Interactive Virtual Bags
- Organise belongings into virtual luggage bags.
- Add, remove, and move items between bags.
- Track bag weight in real time.
- View baggage capacity through visual weight indicators.

### 4. Bag Guard – Smart Baggage Validation
Checks packed items against configured baggage rules.

- Identifies prohibited and restricted items.
- Flags items that may require special attention.
- Detects overweight bags.
- Helps travellers identify potential packing issues before departure.

### 5. AI-Powered Item Classification
Powered by Google Gemini AI, this feature helps classify unfamiliar items.

- Uses predefined keyword-based rules first.
- Uses AI to classify items that cannot be identified through existing rules.
- Assigns relevant categories such as liquids, sharp objects, batteries, power banks, and flammable items.
- Marks uncertain classifications as **Not Verified**.

### 6. Gate-Ready Score
Provides an overall packing compliance score out of 100.

The score considers:
- Restricted or prohibited items.
- Baggage weight violations.
- Missing essential items.
- Packing warnings.

It gives travellers an easy way to understand how ready their luggage is.

### 7. Saved Trips
Save and manage packing lists for different journeys, making it easier to revisit travel preparations.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **AI Integration:** Google Gemini API
- **Data Storage:** JSON-based storage
